# 镜序 MVP

面向漫剧创作者的单镜动态短片工作台。用户可以选择零成本本地合成，也可以使用自己的 API Key 调用即梦（火山方舟 Seedance）、可灵或其他兼容接口。

## 当前可用能力

1. 上传 PNG、JPG 或 WebP 角色图。
2. 使用浏览器端分割模型生成透明背景角色图。
3. 在本地合成、即梦、可灵和其他 API 之间自行选择。
4. 本地模式支持场景、字幕、时长与推进 / 呼吸 / 横移运镜，并导出 720 × 1280 WebM。
5. 云端模式把角色原图与提示词交给所选供应商完成图生视频，并轮询任务直至返回结果。
6. 在工作台中预览结果，下载本地视频或打开供应商结果。

本地模式的图片和视频只在用户浏览器中处理，不消耗 API。云端模式采用 BYOK（Bring Your Own Key）：API Key 只随当次请求转发给所选供应商，不写入数据库、日志或浏览器存储，调用费用计入密钥所属账户。首次本地抠图需要下载并缓存模型文件。

## 供应商配置

- 即梦：使用火山方舟 Seedance 接口，默认模型 `doubao-seedance-2-5-260628`。
- 可灵：使用 Kling AI 图生视频接口，默认模型 `kling-2.5-turbo`。
- 其他 API：创建接口需接受 Bearer Token 以及 `{ model, prompt, image, duration, aspect_ratio }`；查询地址可包含 `{task_id}`，也可由系统在末尾追加任务 ID。接口需返回可识别的 `id` / `task_id`、`status` 和 `video_url`。

自定义接口只允许 HTTPS 公网地址，并拒绝本机和常见内网地址。

## 明确边界

本地模式是“智能抠图 + 动态视频合成”，不生成新动作。云端模式会产生第三方模型费用，并受对应供应商的账号、地区、额度和内容政策约束。

## 本地运行

```bash
npm install
npm run dev
```

建议使用最新版 Chrome 或 Edge。
