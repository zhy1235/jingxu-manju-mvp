# 镜序 MVP

面向漫剧创作者的单镜动态短片工作台。这个版本不再使用滤镜冒充生成结果，而是完成一条可验证、可交付的真实链路。

## 当前可用能力

1. 上传 PNG、JPG 或 WebP 角色图。
2. 使用浏览器端分割模型生成透明背景角色图。
3. 选择场景模板或上传自己的背景。
4. 设置字幕、时长与推进 / 呼吸 / 横移运镜。
5. 在浏览器中逐帧合成并编码 720 × 1280 WebM 视频。
6. 预览并下载视频。

图片和视频只在用户浏览器中处理，不依赖服务端 API，也不会消耗站点所有者的模型额度。首次抠图需要下载并缓存模型文件。

## 明确边界

这是“智能抠图 + 动态视频合成”MVP，不是文字生成动作视频。产品当前验证的是用户能否从一张角色图完成一个可下载镜头，以及抠图成功率、生成完成率和导出率。

## 本地运行

```bash
npm install
npm run dev
```

建议使用最新版 Chrome 或 Edge。
